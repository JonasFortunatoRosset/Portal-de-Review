# Portal de Review
Esse projeto é uma solução para clientes da área de tecnologia que realizam compras baseado
em avaliações de outros usuários. Diante desse cenário o objetivo é incentivar a comunidade a escrever avaliações de qualidade e coerentes. Para isso a **Falkon** decidiu dar um incentivo de R$ 5,00 na carteira para cada avaliação enviada.

### Requisitos para rodar o projeto
Node.js

### Clonar o repositório 
```bash
git clone https://github.com/JonasFortunatoRosset/Portal-de-Review.git
```
### Comandos para rodar o projeto
Utilize ```npm install``` para instalar as dependências necessárias em package.json

Utilize ```npm run server``` para rodar a FAKE API

Utilize ```npm run dev``` para rodar o projeto em modo de desenvolvimento

### Dependências utilizadas

| Dependência | Versão | Função |
| :--- | :---: | :--- |
| `react-router` | `7.17.0` | Gerenciamento de rotas da aplicação |
| `json-server` | `0.17.4` | API Fake para simulação de banco de dados |
